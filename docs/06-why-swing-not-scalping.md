# 왜 1분봉 단타가 아니라 스윙인가

> **이 문서의 위치.** [04-roadmap.md](04-roadmap.md)의 2026-05-31 미션 개정
> ("현물 1분봉 단타" → "스윙 기반 실제 수익")의 **근거**를 정리한다. 결론은
> 하나다: **리테일이 Python 봇으로 1분봉 단타에서 꾸준히 수익 내기는 구조적으로
> 거의 불가능하다.** 이유는 하나가 아니라 여러 개가 곱해져서 죽는다.

---

## TL;DR

```
실현 손익 ≈ (작은 알파) − 수수료 0.2% − 스프레드 − 슬리피지 − 역선택 손실
            └ 0.01%대 ┘   └─────────── 합쳐서 0.2%대 이상 ───────────┘
```

분자(예측 가능한 엣지)는 작은데 분모(거래 비용)는 크고 **확정적**이다.
거래를 많이 할수록 **비용은 확실히 누적되고 엣지는 평균으로 회귀**한다.

---

## 1. 수수료 마찰 — 이것만으로 거의 결정적

Binance 현물 taker 수수료는 한 번에 0.1%. 진입+청산 왕복이면 **0.2%**.
단타는 거래가 잦은 게 본질이라 이 비용이 누적된다.

핵심은 **비용은 확정적이고 엣지는 확률적**이라는 점:

- 거래 1000번 → 수수료 0.2% × 1000 = **누적 200%의 확실한 마이너스 마찰**
- 이를 메우려면 거래당 평균 +0.2%를 *순수 알파로* 벌어야 한다

> 비유: 동전이 51% 앞면이 나오게 살짝 조작돼 있어도(=진짜 엣지), 한 번
> 던질 때마다 판돈의 20%씩 참가비를 내면 절대 못 번다.

## 2. 1분봉엔 0.2%를 이길 "예측 가능한 신호"가 없다 (신호 대 잡음)

BTC 1분봉 한 칸의 변동은 보통 ±0.05~0.1%. 그리고 이 움직임의 **거의 전부가
무작위 노이즈**다. 1분 뒤 가격의 예측 가능한 성분(알파)은 잘해야 0.01~0.02%
수준 — 수수료 0.2%의 **10분의 1도 안 된다.**

즉 신호가 *진짜로* 예측력이 있어도, 그 예측력의 크기 자체가 비용 장벽보다
훨씬 작다. **맞춰도 못 버는 구조다.**

## 3. 스프레드 + 슬리피지 — 수수료보다 더 무서운 숨은 비용

수수료 0.2%는 *명시적* 비용일 뿐이다. 실제로는:

- **호가 스프레드** — 시장가 주문은 매수/매도 호가 차이를 넘어가며 체결
- **슬리피지** — 주문이 호가창을 잡아먹으며 평균 체결가가 밀림

이 코드베이스가 `Trade.entry_slip_bps` / `exit_slip_bps`를 측정하는 이유가
바로 이것. 1분봉에선 이 숨은 비용이 알파보다 크다.

## 4. 역선택(adverse selection) — 더 빠른 상대와 싸운다

1분봉 단타 시장에는 **마켓메이커·HFT**가 있다:

- 콜로케이션(거래소 옆 서버)으로 **마이크로초** 단위 반응
- 당신이 시장가 주문을 넣는 순간, 불리한 움직임 직전에 당신을 "픽오프"

리테일 Python 봇은 인터넷 지연만 수십~수백 ms. **속도로 결정되는 게임에서
구조적 약자**다. 좋은 가격을 잡았다고 느끼는 순간이, 사실은 더 빠른 누군가가
떠넘긴 가격일 때가 많다.

## 5. 백테스트가 가장 심하게 거짓말하는 영역

고빈도일수록 백테스트와 현실의 괴리가 커진다:

- 엔진은 "다음 봉 시가 체결"을 가정 → **스프레드를 0으로 친 낙관**
- 거래당 미세한 가짜 엣지가 1000번 쌓이면 백테스트는 화려하지만, 실거래에선
  스프레드/슬리피지로 전부 증발
- 거래가 많을수록 노이즈를 "패턴"으로 착각하기 쉬움 (과적합)

---

## 그래서 스윙이 답인 이유

핵심은 **"노리는 움직임을 비용보다 훨씬 크게 만드는 것"**이다. 비용 구조
(왕복 0.2%)는 타임프레임과 무관하게 똑같다. 단타는 분자(움직임)를 비용보다
*작게* 만들고, 스윙은 비용보다 *100배 크게* 만든다.

| | 1분봉 단타 | 4h~1d 스윙 |
|---|---|---|
| 노리는 움직임 | ~0.1% | **5~20%** |
| 왕복 비용 | 0.2% (움직임의 2배 ❌) | 0.2% (움직임의 1~4% ✅) |
| 비용 대비 신호 | 비용이 압도 | **신호가 압도** |
| 연간 거래 수 | 수천 회 | 수십 회 |
| 속도 경쟁 | 치명적 | 거의 무관 |
| 백테스트 신뢰도 | 낮음 | 상대적으로 높음 |

게다가 크립토에서 OOS(out-of-sample)로 살아남는 거의 유일한 아노말리가
**추세추종/모멘텀**이고, 이건 긴 타임프레임에서 작동한다. 단타에서 스윙으로
옮기는 순간, *이길 수 없는 게임*에서 *이길 가능성이 있는 게임*으로 이동한다.

## 정직한 단서

- **HFT 펌은 1분 이하에서도 돈을 번다.** 하지만 그건 **수수료 리베이트 +
  콜로케이션 + 큐 우선순위 + 마이크로초 인프라**라는 완전히 다른 게임이다.
  리테일 Python 봇이 들어갈 수 있는 판이 아니다.
- **스윙도 공짜 점심은 아니다.** 비용 장벽을 넘을 뿐, 추세추종이 미래에도
  통한다는 보장은 없다. 그래서 [04-roadmap.md](04-roadmap.md)의 게이트
  (B&H 위험조정 초과 + walk-forward OOS + Monte Carlo)를 통과해야만 라이브로
  간다. **통과 전략이 0개면 그것도 정당한 결론이다.**
